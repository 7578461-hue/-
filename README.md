# Семейный бюджет

Веб-приложение для контроля личного и семейного бюджета: доходы, расходы,
персонал, жильё, транспорт, кредиты, накопления, бюджеты с лимитами,
календарь платежей и отчёты — в одном месте.

Первый рабочий прототип: все расчёты выполняются автоматически из списка
операций, данные сохраняются в браузере и переживают перезагрузку.

## Возможности

- **Главная** — 8 карточек-показателей (доходы, расходы, остаток, семья, жильё,
  персонал, накопления, предстоящие платежи) с изменением к прошлому месяцу,
  индикатор бюджета месяца и 6 графиков: доходы/расходы, структура расходов,
  расходы по дням, динамика остатка, сравнение месяцев, топ-5 трат.
- **Операции** — таблица с фильтрами (период, категория, член семьи, тип,
  способ оплаты, обязательность), поиском, добавлением, редактированием,
  дублированием и удалением.
- **Доходы** — план/факт/разница по источникам, план наследуется по месяцам.
- **Семья / Жильё / Транспорт** — разбивка по категориям; у семьи — «кто тратил»,
  у жилья — регулярные платежи со статусами.
- **Персонал** — сотрудники (оклад, день выплаты), авансы, премии, статусы
  «оплачено/частично/не оплачено», выплата в один клик.
- **Кредиты и долги** — остаток пересчитывается по привязанным платежам.
- **Накопления** — цели с прогрессом, пополнение из карточки цели.
- **Бюджеты** — общий лимит месяца и лимиты по направлениям/категориям;
  жёлтое предупреждение с 80%, красное при превышении; наследуются по месяцам.
- **Календарь** — сетка месяца со статусами 🟢 оплачено / 🟡 скоро /
  🔴 просрочено / ⚪ ожидается, список платежей, управление регулярными.
- **Отчёты** — итог месяца, сравнение с прошлым, обязательные/необязательные,
  по членам семьи, по персоналу, по категориям.
- **Настройки** — валюта (не фиксирована), члены семьи, свои категории,
  экспорт/импорт JSON, демо-данные, полная очистка.
- Быстрое добавление операции из шапки/FAB, светлая и тёмная темы,
  адаптивная мобильная вёрстка.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
```

Сборка: `npm run build` — статика в `dist/`, плюс `dist/artifact.html` —
однофайловая версия приложения (можно открыть где угодно).

При первом запуске приложение предложит выбрать валюту и, по желанию,
загрузить **демо-данные** (условные тестовые суммы, помечаются баннером
и удаляются одной кнопкой в настройках).

## Стек

Vite + React 18 + TypeScript, Recharts для графиков, CSS-переменные
(дизайн-токены, светлая/тёмная темы), без UI-фреймворков.

## Архитектура данных

Единственный источник правды — список операций (`Transaction`). Остатки по
кредитам, прогресс целей, статусы платежей и лимиты **вычисляются** из
операций селекторами (`src/state/selectors.ts`), поэтому все цифры
обновляются автоматически после любого изменения.

Связи: операция может ссылаться на сотрудника (`employeeId`), кредит
(`debtId`), цель (`goalId`) или регулярный платёж (`recurringId`) — так
выплата закрывает платёж в календаре, уменьшает долг или пополняет цель.

```
src/
  types.ts             — модель данных
  data/catalog.ts      — направления и ~60 стартовых категорий
  data/demo.ts         — демонабор (все записи помечены demo: true)
  state/store.tsx      — reducer + persist через StorageAdapter (localStorage)
  state/selectors.ts   — все расчёты (чистые функции)
  state/ui.tsx         — месяц, hash-роутер, быстрое добавление, тосты
  lib/                 — форматирование, тема графиков
  components/          — UI-примитивы, графики, таблица операций, формы
  pages/               — 13 вкладок
design/mockup.html     — дизайн-макап, с которого начиналась разработка
```

Хранение изолировано интерфейсом `StorageAdapter`, состояние версионируется
(`schema`) и мигрируется при загрузке — это точки расширения для будущего:
серверная база данных, авторизация и несколько пользователей, импорт
банковских выписок и Excel/CSV. Резервная копия — экспорт/импорт JSON в
настройках.
